# Security policy

PixelGuard's supported line is the latest release on `main`.

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private
**Security → Report a vulnerability** flow for this repository and include:

- affected module and version;
- minimum reproduction;
- expected and observed behavior;
- potential impact;
- a suggested mitigation, if known.

Reports will be acknowledged as soon as practical. Image parser vulnerabilities in Android, Coil,
or Glide should also be reported upstream when PixelGuard does not introduce the behavior.
